# Roshini Suresh — Professional Data Analyst Portfolio

A responsive, recruiter-focused static portfolio for GitHub Pages, Netlify, Vercel, or any static hosting service.

## Personalize before publishing
1. Replace `YOUR_EMAIL@example.com` in `index.html`.
2. Replace the LinkedIn and GitHub URLs in `index.html`.
3. Add your real GitHub repository links to each project case study.
4. Add your actual Tableau/Power BI dashboard screenshots or links when ready.
5. Add your final resume as `resume.pdf` and add a resume button if desired.

## Publish with GitHub Pages
Create a repository named `<your-username>.github.io`, upload the contents of this folder, then enable GitHub Pages from repository Settings → Pages.

## Publish with Netlify/Vercel
Upload/import the folder as a static site. No build command is required.

## Notes
The project visualizations are CSS illustrations, so the site works without external image assets. Replace them with real dashboard screenshots for the strongest recruiter presentation.
